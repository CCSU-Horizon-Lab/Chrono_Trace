# ChatMind —— 聊天心境
## 简介:
### 聊天心境是一款桌面级（~~跨平台~~）应用，基于Pywebview框架开发，使用Python语言编写，用于帮助用户与其好友进行聊天，记录聊天内容并基于聊天内容生成专属定制化建议，在用户和聊天对象进行聊天的时候，根据用户的需求给出更符合用户预期的发展方向的聊天话术建议。除此之外，还提供了一些其他功能，如：阶段性情绪曲线图、实时情绪分析饼状图、聊天词云等等。
## 技术架构：
- 前端: Vue.js
- 后端: Python
- 数据库: SQLite3
- 框架: Pywebview
## 具体页面功能介绍
首先分为四个页面，每个页面对应自己的功能
### 首页 
功能： 介绍项目、注意事项、免责声明、开始引导、聊天记录抓取

### 情绪数据界面
- 选择日期区间，基于聊天记录生成对应的情绪曲线图、聊天频率图、聊天词云等数据展示
### 建议界面
- 使用LLM大模型，基于聊天记录生成建议，根据用户选择的发展趋向（亲密/维持/疏远），来生成不同的建议，设有输入框，用户可以实时的给ai发送信息，来调整ai的输出
### 设置页面
- 配置聊天对象、聊天记录抓取时间间隔、聊天记录抓取时间范围、使用的LLM大模型和apikey等
