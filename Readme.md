# Chrono Trace —— 时痕（项目计划书）

####  —— “镌刻对话年轮，丈量心动间距”

## 1. 项目概述
Chrono Trace 是一款桌面级应用，基于 PyWebView + Python 后端与 Vue 前端构建，面向个人用户，通过对微信聊天记录进行分析，提供情绪洞察与关系发展建议，辅助用户在对话中更从容地决策与表达。

## 2. 项目目标与价值
- 帮助用户理解自身及对话对象的情绪变化与互动模式。
- 基于历史聊天数据与用户意图（亲密/维持/疏远）生成定制化建议与话术。
- 提供可视化与实时分析，提升表达质量与关系满意度。

## 3. 目标用户与使用场景
- 用户画像：重视沟通质量、愿意复盘聊天记录的个体；对情绪管理与人际关系有提升需求的用户。
- 使用场景：
  - 与伴侣/朋友/同事的聊天复盘与策略制定。
  - 重要对话前的准备与话术优化。
  - 持续跟踪某段关系的互动频率与情感走向。

## 4. 核心功能
- 聊天记录管理：导入/抓取聊天记录，支持时间范围与间隔配置。(参考wxdump/chat log)仓库
- 情绪数据可视化：
  - 阶段性情绪曲线图（趋势与波动）。
  - 聊天频率图（密度、活跃时段）。
  - 词云（高频词与主题）。
  - 实时情绪分析饼图（当期占比）。
- 建议生成：
  - 依据发展趋向与聊天上下文生成策略与话术。
  - 支持实时与 AI 交互微调输出。
- 设置与偏好：聊天对象管理、抓取策略、模型与 API Key 管理、隐私选项。

## 5. 交互流程与信息架构
- 首页：项目介绍、免责声明、引导、聊天记录抓取入口。
- 情绪数据：日期区间选择 → 图表展示 → 生成阶段性总结(可做阶段性上下文)。
- 建议界面：选择发展趋向 → 加载上下文 → 生成建议 → 用户微调 → 保存建议。
- 设置：模型/密钥/抓取范围/对象配置 → 测试连接 → 保存。

## 6. 技术架构
- 前端：Vue.js（组件化、状态管理建议采用 Pinia/Vuex）。
- 框架：PyWebView（桌面容器，前后端桥接）。
- 后端：Python（FastAPI/Flask 作为内嵌服务，或直接通过 PyWebView API 暴露接口）。
- 数据库：SQLite3（本地持久化，表结构见下）。
- 模型接入：可插拔 LLM（OpenAI、Azure OpenAI、Claude、国内厂商等，统一抽象适配层）。

## 7. 数据库与数据流程
- 表结构（建议）：
  - `conversations`：会话元信息（对象、创建时间）。
  - `messages`：用户消息记录（会话ID、发送方、时间戳、内容、情绪标签）。
  - `analysis_snapshots`：分析快照（时间区间、统计指标、图表配置）。
  - `suggestions`：AI建议对话记录（趋向、生成时间、摘要、完整话术）。
  - `settings`：用户设置（模型、抓取策略、隐私设置）。
- 数据流：导入/抓取 → 预处理（清洗、去重、分段） → 情绪与主题分析 → 可视化与建议生成 → 存档与复用。

## 8. LLM 集成方案
- 适配层：`LLMProvider` 接口统一 `complete()`/`chat()` 能力，配置优先级：环境变量 > 设置页。
- 上下文构建：选取最近 N 条对话 + 主题摘要 + 用户目标（亲密/维持/疏远）。
- 安全与成本控制：
  - Token 截断与摘要压缩。
  - 敏感信息脱敏（姓名/手机号等替换）。
  - 响应缓存与重试策略。

## 9. 分析与可视化
- 情绪识别：基于词典+简单分类器或 LLM 标签（正向/负向/中性/细粒度）。
- 频率与活跃度：按天/小时聚合，支持滑动窗口。
- 词云：停用词过滤、词形还原、主语动宾抽取做主题增强。
- 前端图表：ECharts 或 Chart.js；导出图片/PDF。

## 10. 隐私与安全
- 全量本地存储与处理，不默认上传第三方。
- API Key 加密保存（系统密钥或用户主密码）。
- 明确的隐私设置与「本地优先」策略；提供数据清理与一键导出。
